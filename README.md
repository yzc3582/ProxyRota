# ProxyRota

`ProxyRota` 是一个面向 Rotaeno 玩家的自动化 B40 / Rating 追踪工具。它通过 QQ 官方机器人协议，作为一个“代理”自动与群内的查询机器人（如 RotaBOT）交互，定时拉取并保存你的 B40 图片，方便在 OBS 等直播软件中实时展示。

项目采用 **生产者-消费者** 架构：GUI 或定时器作为生产者，将指令放入队列；唯一的后台 Worker 作为消费者，串行执行指令，从根本上杜绝了多指令并发导致的状态错乱。同时，针对扫码登录、快捷登录、定时拉取等场景，代码做了精细的状态隔离与超时处理。

## ✨ 功能特性

- **定时自动拉取**：按设定间隔，自动执行 `/r update` → `/b40`，并将 B40 图片保存到本地。
- **通用图片捕获**：除 B40 外，手动执行的任何指令（如 `/r me`、`/r chart`）如果返回图片，也会自动保存，支持通过 `{cmd}` 占位符自定义文件名。
- **精准登录拦截**：
  - 识别 `/login cn|global|国服|国际服`，进入带 130 秒倒计时的扫码等待状态，期间暂停定时任务，并支持手动取消。
  - 识别好友码 / 会话码格式，走瞬时完成的“快捷登录”流程。
  - 无参数的 `/login` 原样放行，用于获取官方帮助文本。
- **单 Worker 队列**：所有指令（定时、手动、登录）进入同一队列串行执行，不会出现两条消息同时发给 RotaBOT 的情况。
- **GUI 控制台**：基于 Tkinter，提供状态栏、实时日志、登录按钮与指令输入框，与后台异步事件循环安全隔离。
- **配置外置**：敏感凭证（AppID、AppSecret、OpenID）全部通过 `.env` 文件管理，适合直接开源。

## 📦 环境要求

- Python 3.8+
- 一个已通过 QQ 开放平台认证的机器人应用（个人主体即可）
- 已加入 RotaBOT 的 QQ 群聊

## 🚀 快速开始

### 记得开启 QQ 群聊的“主动发言”开关（“机器人主动在群聊内发言”）

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置（关键：获取两个 OpenID）

复制 `.env.example` 为 `.env`，填入你的信息：

```ini
APP_ID=你的AppID
APP_SECRET=你的AppSecret
GROUP_OPENID=目标群的OpenID
ROTABOT_OPENID=RotaBOT的OpenID

SAVE_PATH_B40=b40_latest.png
SAVE_PATH_OTHER=img_{cmd}.png
```

`APP_ID` 和 `APP_SECRET` 可以在 QQ 开放平台的机器人开发设置页找到。**两个 OpenID 无法直接查看 QQ 号获得，需要通过其它方法来捕获。**

具体方法详见 `OpenID.md`。

### 3. 运行

```bash
python proxy_rota.py
```

启动后，Tkinter 控制台会显示连接状态。点击“登录 国服”或“登录 国际服”完成首次绑定，之后定时任务便会按默认 300 秒的间隔自动拉取 B40。

## 📖 使用说明

### 登录

- **扫码登录**：点击 GUI 按钮或在输入框输入 `/login cn`（国服）/ `/login global`（国际服）。程序会拦截该指令，进入专用登录状态，**请直接在群聊中扫描 RotaBOT 发出的二维码**，程序本身不显示二维码。扫码成功后状态自动解除；若 2 分钟内未扫码，程序会捕获 RotaBOT 的超时回显并安全退出登录状态。你也可以随时点击“放弃登录”手动终止。
- **快捷登录**：直接在输入框发送 `/login 你的好友码` 或 `/login 你的会话码`。程序会将其识别为瞬时任务，发送后等待“绑定成功”或错误回显，并立即打印结果。

### 手动指令与图片保存

输入框支持发送任意 `@RotaBOT` 指令。指令执行后：

- 如果 RotaBOT 返回图片，程序会根据 `.env` 中的 `SAVE_PATH_OTHER` 模板自动保存。例如发送 `/r chart`，默认会保存为 `img__r_chart.png`；多图会自动追加 `_0`、`_1` 等序号。
- 如果返回纯文本（如错误提示、帮助信息），会直接显示在日志区。
- **登录扫码期间，程序会拦截所有非登录指令**，防止干扰 RotaBOT 的登录上下文。

### OBS 集成

将 `.env` 中的 `SAVE_PATH_B40` 指向的图片文件添加为 OBS 的**图像源**，并勾选“当文件发生变化时重新加载”（或使用脚本定时刷新）。每当程序完成一次 B40 拉取并覆盖该文件，OBS 画面便会自动更新。

## ⚠️ 注意事项

- **不要将 `.env` 提交到 Git**。`.gitignore` 已默认排除该文件。
- RotaBOT 的服务由社区开发者维护，使用时应遵守其使用规范，避免高频轰炸指令。
- 本项目使用 QQ 官方机器人协议，**不涉及第三方框架，无封号风险**，但也因此受限于官方 API 的能力边界（例如无法主动获取群成员列表，OpenID 必须通过事件被动捕获）。
